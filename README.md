# Love Universe ✨

An interactive romantic night sky built with React and HTML Canvas. Discover glowing stars, animated heart-shaped particles, and heartfelt messages with every click.

## Features
- Interactive particle heart animations
- Glowing blue, white, and pink stars
- Romantic messages revealed on click
- Responsive, full-screen experience
- Lightweight frontend implementation

## Tech Stack
- React
- JavaScript
- HTML Canvas
- CSS Animations
- Vite

## Getting Started
```bash
npm install
npm run dev
```

Created as a creative frontend experiment in interactive animations and visual storytelling.
